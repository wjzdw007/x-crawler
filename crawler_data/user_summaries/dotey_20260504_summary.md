**新工具/技术**（如有）
- CC Switch：开源免费工具，整合多种 LLM/代码模型（Claude Code、Codex 等），用于 AI 编码工作流管理与模型切换。
- WORKBank 框架（Stanford 研究引用）：将工作任务按“工人渴望 vs AI 能力”分成四象限，便于评估自动化优先级。
- “GPT Image 2 Prompt” / 绘本插画 Prompt 模板：结构化的竖版多段分镜、材质与排版指令，是可复用的高质量图像生成提示词范式。

**核心观点/方法论**（如有）
- 四象限模型（Green/R&D/Red/Low）：把任务拆解到“高渴望/高能力”等象限，帮助判断哪些任务适合优先自动化或作为创业切入点。
- 初期 AI 使用存在采用者偏差：现有工具使用数据（如 Claude 占比低）反映早期采用者偏好，不能直接等同真实职场需求。
- Prompt 细节决定输出可用性：明确材质、纸张颗粒、分镜与文字排版等要素，会显著提升生成插画的可用程度和可编辑性。
- 合规与 IP 风险需前置评估：直接请求受版权保护角色（如奥特曼、葫芦娃）涉及法律/平台风险，应在设计时规避或取得授权。

**实践经验/案例**（如有）
- 快速兑现价值：优先实现 Green Light 任务（数据录入、例行报告、标准化客服等），能最快体现 ROI 并降低组织阻力。
- 把握创业机会：R&D 区（跨系统协调、长上下文研究、项目计划）是用户渴望高但 AI 能力不足的空间，适合创业长期布局。
- 任务细分而非岗位替代：像程序员这类职业会被任务化拆分——部分可被自动化，部分仍需人类承担沟通、决策与责任环节。
- 绘图类 Prompt 落地要点：指定纵横比、分镜数量、材质质感、文字可读性与高亮词，能直接产出接近成品的书页草稿。
- 校验来源与信任：对工具/下载链接（如 CC Switch）要以作者官方渠道为准，避免使用非官方或收费盗版版本。
- 推荐落地策略：短期做 2–3 个 Green Light 自动化原型以快速验证价值，同时投入 1 个 R&D 用例验证长期机会与产品差异化。
