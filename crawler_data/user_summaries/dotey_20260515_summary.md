**新工具/技术**（如有）
- 飞书 CLI：用于抓取飞书文档并导出为 Markdown、下载文档图片，平台对 Agent 集成友好，社区热度高（star 过万）。
- Claude（Anthropic）：擅长在大量历史文件中做信息检索、上下文推理和代码/逻辑审查，适合“翻遗物＋找 bug”类任务。
- btcrecover：开源比特币钱包恢复工具，配合 LLM 可定位备份与修复拼接 bug，最终解锁私钥。
- Qwen3-ASR / Qwen3-ForcedAligner / LattifAI：推荐用于长音频识别与更准确的时间轴/对齐，幻觉率低于 Whisper。
- 推荐 VAD 切片工具（作者项目 l5yvfDJUOs）：用于更准确的语音切片，提高后续 ASR 与分段质量。
- ChatGPT 金融账户接入（Plaid + Intuit）：在 ChatGPT 内绑定银行/投资账户，实现基于真实数据的理财查询与代办能力。

**核心观点/方法论**（如有）
- 开源项目可靠性判断标准：看 Star、Commit 历史、Issues 数量与关闭速度、PR 合并记录；这些指标能较客观反映维护与社区活力。
- LLM 的优势在于语料挖掘和逻辑梳理，不是纯算力暴力破解；更擅长找线索、定位备份和修复工具逻辑错误。
- 平台对 Agent 友好度决定落地成本：飞书被评为国内对 Agent 最友好的平台，便于集成与实践。
- FDE 趋势：AI 时代更需要懂客户、懂产品并能动手实现的复合型工程师（FDE），以连接场景理解与落地实现。
- 产品整合为战略选择：OpenAI 将 ChatGPT 与 Codex 合并，说明把聊天、自动执行与编码能力做成统一体验是竞争与上市前的逻辑。

**实践经验/案例**（如有）
- 实操：dotey 自己常用飞书 CLI 抓取文档并转 Markdown／下载图，验证了工具在文档自动化上的价值。
- 案例：用户借助 Claude 找回 11 年前丢失的 5 BTC——LLM 在发现旧备份和找到 btcrecover 拼接 bug 上起决定性作用。
- Prompt Engineering：作者分享的“毒舌版”微信群总结提示词，展示了如何在风格控制与安全红线间写出高冲击力文本。
- ASR 实践：对于长访谈/字幕链路，放弃 Whisper、改用 Qwen3-ASR + 更稳的对齐工具和 VAD，能显著提升时间轴与识别准确率。
- 产品洞见：ChatGPT 绑账户把“建议”变“代办”，但隐私与数据控制（断开、删除、financial memories 管理）是能否普及的关键。
