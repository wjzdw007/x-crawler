**新工具/技术**
- baoyu-comic skill（移植到 Hermes Agent）：把 prompt 或源文档转成多页知识漫画，支持多种风格/语气/版式，适合知识可视化与教学场景。
- Antigravity 2.0（Google）：桌面级 agent 优化应用，支持多 agent、定时任务和本地语音，UI/UX 风格接近 Codex。
- Gemini 新 UI（产品改动）：取消侧边栏固定常用 Gems，影响常用工具的快速访问和日常工作流效率。

**核心观点/方法论**
- 用户体验决定效率：产品对常用入口的设计直接影响使用频率和满意度，设计改动应以真实工作流为准绳。
- 借鉴优良 UX 是实际可取的：若复制能提升可用性，应开放接受并做本地化改造与验证。
- 重视平台状态与资源策略：Codex 重置提醒大家要考虑 token/历史产出价值与备份策略，避免单点损失。

**实践经验/案例**
- 技术移植示范：将个人 skill 模块化并集成到 agent 平台（baoyu-comic → Hermes Agent）是放大工具价值的有效路径。
- 工作流反馈来源：Gem 管理改动构成真实的效率痛点，用户反馈可作为产品迭代的重要输入。
- 备份与高频使用教训：Codex 重置的遗憾说明对关键数据应多处保存或在平台稳定期优先导出/利用。
- 关注人才流动以判断方向：转发 Karpathy 加盟 Anthropic 表明对前沿研发团队动向的重视，可作为技术路线和招聘判断参考。

**结论/建议**
- 工具作者：把高频功能做成快捷入口并考虑被 agent 平台吞并或集成的可能性。
- 使用者：常用资源要定期导出/备份，遇 UI 改动及时调整工作流并反馈产品团队。
- 产品经理：在采纳他人 UX 时结合本产品用户行为做 A/B 验证，避免一刀切带来效率倒退。
