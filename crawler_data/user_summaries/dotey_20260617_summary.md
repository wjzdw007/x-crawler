**新工具/技术**
- baoyu-design skill：本地运行 Claude Design 的 Skill，可在本地生成动画并直接导出 MP4，解决网页版无法下载的问题。
- 导出流程：用无头 Chromium 加控制接口逐帧设置时间、截图并通过管道交给 ffmpeg 编码，保证每帧可复现且不掉帧。
- 高清渲染技巧：截图时用 2× 设备像素比（先按 3840×2160 输出再用 ffmpeg 缩回 1080p），能显著提升文字和细线锐度。
- 可编辑输出：生成结果默认是 HTML，可在内置浏览器预览并导出可编辑的 PPTX，支持在页面上标记位置让 Agent 修改。
- 开源与影响：项目在 GitHub 开源（MIT），约 1.2K stars，目录 skills/baoyu-design 包含动画引擎实现。

**核心观点/方法论**
- 声明式时间驱动动画：把每一帧视为函数 f(t)，直接描述“在第 t 秒元素应该是什么样”，而不是命令式逐步驱动状态变化。
- 为什么重要：f(t) 使动画可随时寻址、确定且可复现，便于跳帧调试、反复微调与帧级导出。
- 与录屏的对比：录屏是实时且易掉帧并会捕获播放器外壳，逐帧渲染+截图能获得无播放器痕迹的高质量视频。
- 渲染可靠性细节：设置时间点后等待两帧 requestAnimationFrame 再截图，以避免截到未完成的残影。
- 代价与取舍：逐帧“摆好时间、拍照”很慢但换来确定性和像素级质量。

**实践经验/案例**
- 帧计数示例：一段 95 秒、30fps 的动画需要 2,850 次“设定时间—截图—编码”的循环，说明导出时间成本。
- 应用场景：生成宣传视频、可编辑 PPT、教学演示等，适合需要高保真、可回溯的场景。
- 编辑工作流技巧：在 Agent 内置浏览器暂停 HTML 动画并标记要改的位置，让 Agent 基于标注做微调，效率高且无需大量手工改代码。
- 拓展思路：把写作风格等能力做成 Skill，结合内循环（定时任务）与外循环（基于修改自我优化）能实现自进化的内容生成流程。
- 代码位置：感兴趣可查看仓库的 skills/baoyu-design 目录，完整实现和示例都在里面。
