**新工具/技术**
- ChatGPT 桌面端语音控制（基于 GPT‑Live）：全双工语音交互，可以边听边回话并管理多个后台 Agent，支持 macOS/Windows 桌面端（付费计划）。
- GPT‑Live 架构说明：能同时听和说、遇复杂问题把推理丢给后台（如 GPT‑5.5），避免交互阻塞。
- macOS Appshots：语音对话时读取当前最前端窗口的画面上下文，能基于屏幕内容回答（Windows 暂无）。
- iPhone → 桌面 Codex 远程配对：用 iOS 语音远程操控桌面 Codex，Android 支持在路上。
- Claude Opus 5（Anthropic）：定位为接近前沿的高性价比模型（多项 benchmark 提升、API/计价、Fast 模式、自动降级与缓存改进）。
- BaoCut 视频画面翻译功能（dotey 自研）：支持 Agent 自动化识别要翻译的帧、批量队列翻译，并能导出到剪映/CapCut 二次处理。

**核心观点/方法论**
- 用AI生产力时不要逐行读机器写的代码（Uncle Bob 的做法）：通过“用测试和约束包裹 Agent”来保证质量，读代码不再是唯一或最佳的质量手段——重要的是测试、度量和流程化关卡。
- 人机合奏需要产品驱动能力选择：模型能力会在产品选择压力下被“自然选择”，能力进化与产品创新要协同。
- 开发者能力重心在变：从读代码、写代码，向写测试、设约束、构建 Agent 流水线（规格化 → 编码 → 重构 → 架构审查）转移，对组织影响深远。

**实践经验/案例**
- BaoCut 迭代经验：从“单帧翻译”改为“队列批量翻译”显著提速；交互上折衷为字幕叠加而非逐帧替换以兼顾动态画面与可编辑性；推荐用 Codex 自动化流程减少人工干预。
- 关于 Opus 5 的实测案例：在机械零件图重建、开源包修复、交易所行情接入等任务中表现出色，且在安全拦截与自动回退机制上做了工程折中（可查源代码但限制 Exploit 生成）。
- 工具运营与预判：注意模型/产品会调整额度或重置（推测 Codex/Claude Code 会重置）；观察到部分产品（如 DeepSeek）缺少多模态支持会被同行质疑。
