**新工具/技术**（如有）
- BaoCut：dotey 发布的免费工具，支持 YouTube / X 视频的转录、翻译与剪辑一条龙处理，目标降低视频处理门槛。
- 架构要点：GUI 与 CLI 分离，支持 Skill 扩展，并提供网页界面 + “复制 prompt” 功能，便于在 Agent 内无头调用与二次编辑。

**核心观点/方法论**（如有）
- Agent-first：未来入口是 Agent，App 应作为结果确认与微调的界面，实际执行由 Agent 编排完成，这能提高自动化组合能力与可扩展性。
- AI“味”来自惯性：大模型输出有明显训练产生的风格/惯性，单靠提示词难以彻底移除，长期会造成内容同质化与用户疲劳。
- 设计含义：要通过架构（可被 Agent 调用、支持 Skill）和前端可控性（微调界面、二次编辑）来减轻单一惯性的负面影响。

**实践经验/案例**（如有）
- 用户反馈：社群/工程师对 BaoCut 功能评价高（转录→翻译→剪辑流程流畅），但翻译环节需要在 harness 中操作，期望更无缝的无头翻译集成。
- 产品调整：dotey 为此砍掉了内置 Harness，保留 prompt 复制并提供网页界面，允许 Agent 在内置浏览器中打开并直接标注、二次编辑。
- 运营教训：dotey 从做公众号的实践中发现，长期依赖同一套 skill 会形成“味道”，爆文可复制但会导致读者识别出一致风格，需通过差异化或底层训练来解决。
- 实用启示：构建 AI 工具时优先考虑 Agent 调用能力、支持可扩展的 Skill 以及留出人类微调的 UX，既能提高自动化效率，也能控制输出风格。
