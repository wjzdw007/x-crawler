**新工具/技术**
- GPT‑6 Astra：被用于 one‑shot 生成完整 3D 可交互网页，能把提示词直接变成可在线访问的三维场景。  
- BaoCut：宝玉自己的工具，负责字幕识别与视频裁切/导出，便于后续检索和编辑。  
- Jev：与 BaoCut 配合做本地视频检索，基于字幕和语义评分筛出相关片段。  
- Mole（产品测试/清理链路）：用大量真实软件+agent 执行安装/卸载/残留检测，补充清理规则并生成单元测试。  
- Grok 4.7（SpaceXAI）：参数规模和语料显著升级，声称在困难任务上更持久并加入专有工程数据。  
- OpenAI 内部自动化训练智能体：能自动编写 GPU kernel、优化训练代码并让智能体协作运行实验，缩短研发周期。

**核心观点/方法论**
- 分享“提示词 + 制作方法”比单纯展示作品更有价值，因为它能让别人复用并改进生成流程。  
- 用 AI 做重复、枯燥的工程工作（如批量安装/检测）能极大提高效率，并发现实地规则与边界条件。  
- 通用大模型在需要持续观察、多线程决策的实时环境（如 RTS 游戏）仍然表现不足，执行节奏和多任务协调是主要短板。  
- AI 在学术/数学领域的大规模“跑分式”产出会触发方法论与伦理争议，社区参与与透明机制很重要。  
- 模型能力受参数、训练数据（尤其专有语料）与工程细节影响，公开测试与可复现性仍然关键。

**实践经验/案例**
- 宝玉用 GPT‑6 Astra 快速搭出了“牛来版桃花源”3D 网页，并公开提示词与制作流程，鼓励他人改进。在线演示和朗读音频也有提供。  
- 将 Jev 与 BaoCut 结合可以实现“输入一句话从长视频中筛片段”的本地化解决方案，响应快且检索精度高。  
- 用 agent + Compute Use 做 E2E 测试跑通 300+ Mac 软件（百 GB），实际产出 13 类可复用规则、90+ 精确清理路径和 100+ 单元测试，显著提升产品质量。  
- StarCraft（Brood War Bench）测试表明，多数通用大模型只能达到新手水平，最高者倾向“骚扰式”策略而非系统性宏观管理。  
- OpenAI 关于数学突破的宣称引发顶级数学家联名质疑，随后成立独立顾问组（AGMAI）以平衡速度与学术规范。
