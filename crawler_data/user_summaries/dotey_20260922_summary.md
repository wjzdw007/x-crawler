- GPT‑6 Sol / Luna：OpenAI 推出的中/轻量款 GPT‑6 家族，继承旗舰进步并大幅降价，加入更灵活的提示缓存以降低长期使用成本。  
- Grok / Codex Bot（Agent 框架如 OpenClaw）：面向“永远在线”的个人 AI 队友，能登入工具链和跨应用执行任务，代表消费级智能体产品趋势。

**核心观点/方法论**（如有）
- 大规模单次 RL（MixRL + MOPD）：MiMo 团队用 MixRL 在可验证任务上混合训练，并对难以联合训练的任务单独训练后用 MOPD 合并，提升通用性和 rollout 效率。重要性：在有限算力下更高效地扩展 agent 能力。  
- 训练重点从问答向长轨迹智能体转变：强化学习覆盖几万步的工作流程（写代码、调工具、查错、纠偏），意味着能力来自闭环的长期行为优化而非短对话微调。  
- 责任与监管两条路径并存：华盛顿倾向“谁造的谁负责”，业界有减速/第三方评估的呼声，监管走向将直接影响融资、IPO 与安全投入。  
- 成本分层与缓存策略决策：把旗舰能力下放到中/轻量模型并结合提示缓存，是降低开发者长期 Token 成本的关键实践。  
- 工程化文档与渐进披露：把文档统一放 docs、用 README 索引、AGENTS.md 强制同步变化，能把多人/多 Agent 协作的复杂性降到可管理范围。

**实践经验/案例**（如有）
- MiMo 训练规模与成本指标：Pro 模型做了 ~30 个大步、约 75 万条轨迹（每条 11–15 万 token），训练成本约 262 万美元，展示了开源团队也能承担大规模 agent RL 实验。  
- Flash 的性价比场景：Flash 在多项智能体基准仅落后几分，但价格低得多，适合需要大批量跑 agent 任务（代码审查、文档处理、内部助手）的团队。  
- Agent 顾问循环（节省 Token 的实践）：让 Fable 产出方案、Opus 执行、再由 Fable 验收的闭环，能减少人工干预并显著节约高成本模型的调用量。  
- Claude Design 工作流：用 Claude Design 导出 HTML+React 原型并用本地 Skill 维护，能把设计稿直接变成交互原型，减少来回迭代成本。  
- Opus 5.5 的真实收益：在多项实测（代码库审计、语言风格、文档生成）中显著提速并降本，说明模型优化+定价策略能直接改善工程效率。  
- 项目起手与文档实践：dotey 推荐流程：PoC → 用 Claude Design 做功能/方案 → 做 MVP → 迭代；配合 docs 目录与渐进披露能保证团队对方向与验收标准有一致理解。
