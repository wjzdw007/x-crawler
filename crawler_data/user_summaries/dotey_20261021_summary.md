**dotey 的 AI 观察 · 2026年10月21日**

**新工具/技术**
- **Codex Desktop**：不做代码编辑器，左侧任务、右侧对话，改代码只能交给智能体。Tibo 与 Andrew Ambrosino 赌的是“模型能跑长任务后，人会和多个智能体待一整天”。
- **Claude Duet**：会主动找你的助理，云端有自己的电脑，关机也继续干活，6000+ 连接器，美国 Pro/Max 候补；同期还有 Grok Bot、Muse、Dots，四家产品形态已高度趋同。
- **Jev**：不聊天，只在选项里“涂答题卡”，用涂的深浅表达置信度，换来几十倍速度和几美分成本，官方宣称零幻觉。
- **缓存策略更新**：Codex/Work 登录用户缓存永久保留，API 提示缓存可设 12 小时；回到旧会话不再被“惩罚”，长任务成本模型变了。

**核心观点/方法论**
- **模型能力决定产品形态**：Codex 一年内从 Cloud→终端→IDE 侧栏→无编辑器桌面应用，每次模型跃迁都解锁一种新交互，而不是先定产品再等模型。
- **Race to the top**：Dario 承认三处沟通失误，但坚持只有站在前沿才能把安全标准抬给全行业；质疑者的反问是“为什么每次犯错都恰好对自己有利”。
- **开源降价不等于旗舰不赚钱**：成本随芯片和软件同步下降，开源吃低端价格战，旗舰层仍是双寡头；开源占 token 20%+，按金额只占 5-10%。
- **规则抽象比代码抽象更重要**：跨平台重写时，真正能复用的是设计 token、文案、踩坑规则，代码本身反而各写各的。

**实践经验/案例**
- **AI 抢在攻击者前找漏洞**：PHP 两个免登录 RCE（PHP2Shell），Calif 用 GPT-5.6 Sol、Wiz 用 Gemini 4 Argon 独立发现；约 70% 网站跑 PHP，升级是唯一完整解法。
- **本周供应链安全连环爆**：GitLab 六周内第三个满分漏洞（2014 年以来自建版全中）、TiDB Cloud 控制面被入侵（黑客声称窃走 10.6TB）、Railway 环境变量可能被解密、eMudhra 8 枚弱密钥证书——共同动作是轮换密钥、把依赖更新到底。
- **在 Mac 上开发 Windows 原生应用**：Parallels 共享目录 + prlctl 脚本编译、ThinkPad 做真机回归、Codex computer use 点系统弹窗；四层架构让 Core/Platform/ViewModel 都能在 Mac 上测，一个月 8 万行。
- **平台风控已到设备指纹级**：Claude 逆向显示 SIM 卡国家、ANDROID_ID、device_id、IP 轨迹要彼此一致，换号、清数据、多账号共用配置都会被串起来。
