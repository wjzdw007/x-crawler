**核心观点/方法论**
- **Agent 分层价值论**：搭 Agent 最不值钱，给 Agent 做工具、用 Agent 重构工作流更值钱；如同写代码不值钱、用代码解决业务问题才值钱——护城河从“会用框架”转向“懂具体场景业务”。
- **AI 效率的虚无主义**：“AI 省掉全部前戏让你一秒高潮，然后在漫长贤者时间里找人生意义。”压缩过程不等于创造价值，产品设计需保留参与感。
- **订阅额度 A/B 测试**：Anthropic 对部分账号 5 小时额度 +20%、月度总量折合 API 价值 −20%。用户“额度变少”的体感真实，但只影响分组账号——调参正成为隐性的产品策略。

**实践经验/案例**
- **开放权重的安全取舍**：Kimi 训练时删除网络攻防数据，内部漏洞利用测试从 90.5% 降到 81.0%，并称攻击能力仍落后已公开三个月以上的闭源顶级模型，是“能力—开放”权衡的量化样本。
- **平台生态差异**：段子中豆包接管微博迅速被封、Grokbot 在 X 涨粉变现，调侃平台规则与归属关系直接决定 Agent 能否落地。
