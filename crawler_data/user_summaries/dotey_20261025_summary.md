# dotey（宝玉）今日分享分析｜2026年10月25日

**新工具/技术**
- **BaoCut Skill + App**：用提示词让 AI 生成带有档案馆或纪录片风格的排版视频，支持转录、双语字幕对齐、自动分章、检索配图与配色；需要安装 BaoCut App 配合使用。
- **Opus 5.5 + Three.js**：Techartist 用它做出 3D 可视化物理课本《Every Joule》，覆盖英国 GCSE“能量”整章共十课，可免费在线观看。
- **Grokbot、muse 等个人 Agent**：在手机端用几句话就能把事情办完，不需要安装配置，也不用考虑新开 session，因此降低了普通人使用的门槛。

**核心观点/方法论**
- **Agent 走红源于体验落差，技术本身并非主要原因**：高频使用 Claude Code、Codex 的人觉得这些功能很平常，而刚接触前沿 Coding Agent 的人则容易把“聪明模型 + 自动执行”看成科幻片成真；再加上“私人助理”带来的掌控感和情绪价值，所以很容易沉迷。他用大观园的比喻说明这一点：老手看日常，新手看神迹。
- **AI 味取决于使用者品味**：模型默认产出的设计必然带 AI 味；有设计品味的人可以做得好看。工具的真正价值在于提供一种新的音视频展现模式，让你自己组合出不一样的设计。
- **模型做视频应以工程流程为优先，一次性生成并非重点**：先出简报确认，再给审片链接，通过后才导出；过程中分章节、做双语字幕、TTS 解说、检索素材并逐词点亮原话。
- **“手写代码比例”调查显示社区样本存在明显偏差**：Armin Ronacher 在三个平台发起同一投票，X 上仅 12.7% 回答“是”，Bluesky 为 26.4%，Mastodon 高达 75.2%，说明各平台人群画像差异巨大，引用数据时需注意样本来源。

**实践经验/案例**
- **宋美龄 1943 年国会演讲视频**：使用美国国家档案馆保存的 21 分钟原声，本机语音模型转写文字并对照《国会记录》校订，AI 辅助翻译，Gemini TTS 旁白，Opus 5.5 与 baocut 制作，分为六章；他声明自己不是历史博主，只是在测试模型生成不同类型视频的能力。
- **Dario Amodei 2003 年反战演讲**：从帕萨迪纳市议会存档录像中找到 20 岁 Amodei 的 2 分钟发言，加中英双语字幕，串联起 18 年后创办 Anthropic 的叙事线索。
- **手机端 Agent 的关键差异**：Claude Code、Codex 其实也支持手机场景，但便利性不如 Grokbot，核心差距在于无需手动管理 session。
