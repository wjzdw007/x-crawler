- **Gemini 4 Carbon**：Google 最新前沿模型，在 Artificial Analysis v5.0 综合榜以 59 分排第一，但本周只向部分网络安全防御者开放，普通用户和开发者还需等待 Fairwind 计划扩大范围。
- **Claude for Legal 工具库**：Anthropic 为法律版 Claude 上线了一批现成 Artifacts，覆盖引文核查、合同偏差检查、批量条款摘录、法规对比与时间线等，结论都附有原文出处。
- **ChatGPT 订阅送 API 额度**：Pro 每月可领 100/200/500 美元，Business 按付费席位合计上限 500 美元，额度当月有效；Plus、Enterprise 不参与，用 API key 跑 Codex 不能花这笔钱。
- **Claude Code `/autocompact 300k`**：把自动压缩阈值从约 967K 提前到 300K，减少长对话中每轮重复携带的历史 token。

**核心观点/方法论**
- **Agent 剪辑已过可用线**：Opus 5.5 后 AI 能自主完成复杂剪辑，通用模型会吃掉中间工具层；不要重造专业时间线，做好初剪和交接，核心资产是 Skill 与品味。
- **多 Agent 管理像带团队**：重点在设计与验收，不在细碎切任务；异步沟通、按检查点切换注意力，单任务控制在小时级，窗口极限约 3-4 个。
- **“Copilot”是过时概念**：AI 不应只是副驾驶，而应走向自动驾驶；Copilot 的代码审查和 Office 功能实用价值有限，体验比 Claude Code、Codex 差一个量级。
- **大厂推理成本被低估**：按 Anthropic 约 85% 毛利率推算，Opus 5.5 服务成本约 $0.6/$3.0，比不少竞品便宜，价格空间来自推理效率。
- **不必排斥“AI 味”**：就像工业时代不必执着手工制品，关键看产品是否有价值、质量是否够好。

**实践经验/案例**
- **worktree 清理写进 AGENTS.md**：要求任务完成即删除 worktree、分支和专用 cargo target；不合并则提交后打 `archive/<name>` tag 存档；派生子 Agent 的会话负责收尾。
- **剪辑 Skill 训练法**：按风格拆小 Skill，给 4-5 条参考让模型总结，再用资深剪辑师最近 25 条作品重剪并逐条点评，同时录屏口述判断理由；只让最强剪辑师训练。
- **工具层越薄越好**：同一视频不装 MCP、插件，只给 ASR/TTS，Opus 5.5 效果反而更好；BaoCut 的复杂时间线编辑器已退居二线。
- **验收要落到 E2E 证据**：几十上百个单测变绿不能证明符合 spec，需从设计出发做端到端验证，复杂状态可补形式化验证。
- **OpenAI SWE 面试样本**：48 小时 take-home 会被逐行追问设计取舍；部分候选人加考用 AI 编码工具解决手写做不完的问题；系统设计题考 GPU 分配与弹性扩缩。
