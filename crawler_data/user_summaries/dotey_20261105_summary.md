**核心观点/方法论**
- **逆向 Agent Skill 靠“喂上下文”而非直接提问**：先让 Agent 加载 Skill 完成作品，再以“我要做一个一样的”为由让它复述；dotey 补充这适用于所有 Agent 产品分析——用 Claude Duet 触发 `skill_propose` 后再问实现方式，让它先写技术方案即可摸清机制。
- **Addy Osmani 的“软件工厂”**：Anthropic 从 5 月每天 2500 次合并涨到 9 月 3 万次，瓶颈已从写代码转向验证；人不再逐行读代码，而是看 AI 交的录屏、截图等证据，验证做扎实能让产出质量好 2-3 倍。2027 年底多数团队仍是“亮灯工厂”为主、带一些“熄灯角落”。
- **METR 评估**：Anthropic 模型能力提升速度约为此前 2 倍（AECI 1.9 倍），约 8 成可能归功于 AI 参与研发；但最有说服力的证据被大量涂黑，外界只能更多依赖 METR 判断。
- **Thariq 离职访谈**：AI 实验室被过度神化，人不该把身份绑在公司上；硅谷不缺天才，缺的是不去实验室、自己动手试的勇气。

**实践经验/案例**
- **Claude 做科研同样会犯错**：培养基加错添加剂让项目倒退两周，冷冻电镜跳过标准步骤导致结构镜像混淆；团队结论是利远大于弊，但在不熟悉的领域查错更慢，需保留人工核验。
- **个人做 AI 漫剧是伪机会**：行业靠赛马机制加投流批发价，爆款率不足千分之五，个人按零售价买流量无法竞争；应转向广告、婚礼视频等小而美定制。
- **TikTok 逆向**：服务器在播放前已算好“推荐分”，App 实时采集陀螺仪、电量等 50+ 变量，甚至预测下次打开时间提前缓存，其用户状态建模思路值得 Agent 产品参考。
