**核心观点/方法论**
- 「目标→验收→改进」循环：与 Lauren Tan 把人的最佳实践教给 Agent 不同，dotey 只定目标和验收标准，不干涉中间步骤，理由是 AI 更强且模型不限于 Grok。验收标准要能自检，并配截图、检索、代码运行等工具；如新闻自动化必须"动笔前先事实核查"。
- 先跑起来再调整：类比打靶，先开一枪才知道偏多少；真正的专业壁垒是能判断结果好坏，并准确向 AI 描述改进方向，否则只能 AI 给什么接受什么。
- 让 Agent 自我进化：把打磨好的最佳实践沉淀成 Skill（含工具），执行中写 lessons.md 记录经验，再回头优化 Skill；副作用是 Skill 会臃肿，需定期让 Agent 重构，重构后重跑测试集防误删。
