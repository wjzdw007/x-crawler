## 核心动态
- Starship 第十三次试飞瞄准周四发射，任务首次搭载 20 颗 Starlink V3 作为测试载荷，并同时进行热防护与推进相关的多项验证，这将检验发射与在轨检测的协同能力。  
- SpaceX 强调“Starship 正在快速演进”，并列出推进、分离、发动机重点点火与热盾改进，旨在降低复飞风险并提升有效载荷与可复用性。  
- Grok 4.5 被反复宣传为“政治中立且追求客观真相”的模型，并在社区评测中被描述为在某些软件基准上超过竞争对手 Fable，显示其在性能与定位上的双重推进。  
- Grok 产品与工具链正在快速迭代（包含 Build 平台更新和浏览器端表现被称为“Opus 级”），官方多次邀请用户试用以扩大采纳与生态影响力。  

## 值得关注
- 本次试飞有六颗改装卫星配备相机，用于在再入阶段对 Starship 热盾成像并回传，便于未来返场着陆前的可视化评估。  
- 若干热盾瓦片被涂白以模拟缺失并作为成像目标，任务还计划更高动压的上升轨迹和载荷应力测量，测试强度显著增加。  
- Starlink V3 的首次搭载旨在验证可展开太阳翼与激光链路能力，但这些测试卫星预计随次轨道轨迹重返大气，不会长期入轨。  
- 被引用的独立中立性基准指出 Grok 4.5 接近中心（示例数值 -0.02），而其他模型在该测试中整体偏左（示例 -0.41），这一结论已被多方放大传播。  
- 社区评测称 Grok 4.5 在浏览器使用场景达“Opus 级”，并在部分软件基准上略胜 Fable；已有用户用其与 Perplexity 构建实用应用（如个性化播客流）。  
- Grok Build 的更新（多行输入、PageUp/PageDown 对话滚动、Vim 键位兼容等）显示产品正从模型能力向可用性與开发者工作流延伸。  
- 推文中多次强调“Starship 发射 Starlink，Starlink 帮助检测 Starship”，体现 SpaceX 内部产品之间的复合协同价值链。  
- 马斯克关于“能量与质量都是稀缺资源”和太阳能作为终极能源的论述被转发，继续推动其在能源与太空资源利用上的长期议题。
